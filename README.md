# Kurami Mini App

Primera maqueta de la Mini App de Kurami E-Sports.

## Requisitos
- Node.js 20.19+ o 22.12+
- Una cuenta de GitHub para guardar el proyecto
- Una cuenta de Vercel para publicar la web

## Ejecutar en un ordenador
1. Descomprime el proyecto.
2. Abre una terminal en la carpeta `kurami-miniapp`.
3. Ejecuta `npm install`.
4. Ejecuta `npm run dev`.
5. Abre la dirección local que indique Vite.

## Publicación
Sube los archivos a un repositorio GitHub y conecta ese repositorio a Vercel. La URL HTTPS resultante se configurará más adelante en BotFather.

## Seguridad
No incluyas el token del bot en estos archivos ni en el navegador. La validación de `initData` deberá realizarse en un servidor cuando añadamos funciones que guarden datos o identifiquen usuarios.

Esta versión es una maqueta visual: torneos, perfiles, rankings y Pokédex aún no están conectados a una base de datos.
